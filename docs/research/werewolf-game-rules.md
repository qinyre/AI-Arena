# 狼人杀游戏规则完整参考

**整理日期**: 2026-07-23  
**用途**: AI Arena MVP开发参考

---

## 1. 游戏概述

狼人杀（Werewolf/Mafia）是一款多人参与的策略类桌面游戏，通过语言描述、疑问、辩论等形式进行推理和博弈。

**核心机制**: 社交推理、身份隐藏、阵营对抗

**玩家分为两大阵营**:
- **好人阵营**: 村民、预言家、女巫、猎人、守卫等
- **狼人阵营**: 狼人

---

## 2. MVP所需角色（5人局）

### 2.1 狼人 (Werewolf) - 1人

**阵营**: 狼人阵营

**能力**:
- **夜晚行动**: 选择一名玩家杀死
- **身份隐藏**: 白天伪装成好人
- **团队协作**: 在多狼局中，狼人互相知道队友身份（但MVP是单狼局）

**胜利条件**: 狼人数量 ≥ 好人数量

**策略要点**:
- 伪装身份，避免被发现
- 在发言中误导其他玩家
- 投票时避免暴露狼人身份

### 2.2 预言家 (Seer) - 1人

**阵营**: 好人阵营

**能力**:
- **夜晚行动**: 查验一名玩家的身份（得知是好人还是狼人）
- **信息优势**: 拥有确定的身份信息
- **需要跳身份**: 白天可以公开身份并分享查验结果

**策略要点**:
- 选择关键时刻跳身份
- 分享查验信息帮助好人阵营
- 需要防备假预言家（狼人冒充）

### 2.3 村民 (Villager) - 3人

**阵营**: 好人阵营

**能力**: 无特殊能力

**作用**:
- 通过发言和投票参与游戏
- 通过逻辑推理识别狼人
- 支持预言家等神职

**策略要点**:
- 仔细聆听所有玩家发言
- 寻找发言中的矛盾点
- 合理投票

## 3. 游戏流程

### 3.1 初始化阶段

1. **角色分配**: 
   - 随机分配角色（记录随机种子）
   - 狼人知道自己身份
   - 预言家知道自己身份
   - 村民不知道任何信息

2. **首夜**: 
   - MVP版本：第一晚不杀人（平衡游戏）
   - 预言家可以查验一名玩家

### 3.2 游戏循环

#### 夜晚阶段 (Night Phase)

**顺序**:
1. **天黑请闭眼** - 所有玩家进入夜晚
2. **狼人行动**
   - 狼人睁眼
   - 选择一名玩家杀死
   - 记录目标
3. **预言家行动**
   - 预言家睁眼
   - 选择一名玩家查验
   - 系统告知该玩家是好人还是狼人
4. **天亮** - 进入白天

#### 白天阶段 (Day Phase)

**顺序**:
1. **公布死讯**
   - 系统宣布昨晚被杀的玩家
   - 该玩家出局，不能发言和投票

2. **发言环节**
   - 所有存活玩家依次发言
   - 可以：
     - 跳身份（声称自己是预言家等）
     - 分享信息（"我查验了XX是好人"）
     - 指控怀疑对象
     - 分析局势
   - 发言顺序：从被杀玩家的下一位开始顺时针

3. **投票环节**
   - 所有存活玩家同时投票
   - 选择一名玩家放逐
   - 票数最多的玩家出局
   - **平票处理**: MVP版本平票则无人出局，进入下一轮

4. **检查胜利条件**
   - 如果狼人被投出 → 好人获胜
   - 如果狼人数量 ≥ 好人数量 → 狼人获胜
   - 否则进入下一个夜晚

### 3.3 游戏结束

**好人阵营获胜**:
- 狼人被投票放逐

**狼人阵营获胜**:
- 狼人数量 ≥ 好人数量（1≥1，即剩1狼1好人时狼人胜）

## 4. 完整角色参考（v1.0扩展用）

### 4.1 女巫 (Witch)

**能力**:
- **解药**: 一瓶解药，可以救活当晚被狼人杀死的玩家（每局只能用一次）
- **毒药**: 一瓶毒药，可以毒死任意一名玩家（每局只能用一次）

**规则**:
- 女巫在狼人行动后行动
- 可以同一晚使用解药和毒药
- 不能自救（有些版本可以第一晚自救）

**策略**:
- 解药用于保护关键角色（预言家）
- 毒药用于击杀确认的狼人
- 需要判断何时使用技能

### 4.2 猎人 (Hunter)

**能力**:
- 被杀死（投票或狼人杀）时，可以开枪带走一名玩家

**规则**:
- 只有正常死亡才能开枪
- 被女巫毒死不能开枪
- 可以选择不开枪

**策略**:
- 威慑作用大
- 关键时刻可以换掉狼人
- 需要准确判断目标

### 4.3 守卫 (Guard)

**能力**:
- 每晚守护一名玩家，被守护的玩家当晚不会被狼人杀死

**规则**:
- 不能连续两晚守护同一人
- 可以守护自己（但不能连续守）
- 守护和狼人杀同一人，该玩家不死（守护成功）

**策略**:
- 保护预言家等关键角色
- 通过守护判断狼人目标

## 5. 发言技巧和策略

### 5.1 好人阵营策略

**预言家**:
- 首夜查验：建议查验发言积极的玩家
- 跳身份时机：第2或第3天，有足够信息时
- 报查验：先报好人，建立可信度
- 应对假预言家：对比查验信息，让其他玩家判断

**村民**:
- 多说话，提供信息
- 分析发言逻辑
- 寻找矛盾点
- 支持真预言家

### 5.2 狼人阵营策略

**狼人**:
- 伪装：表现得像村民或神职
- 假跳预言家：报假查验结果，混淆视听
- 站队：跟从主流意见，避免孤立
- 反水：关键时刻改变立场，制造混乱

### 5.3 发言要素

**好的发言应该包含**:
1. **信息**: 我知道什么（查验结果、观察）
2. **分析**: 我怎么看（逻辑推理）
3. **立场**: 我怀疑谁（投票倾向）
4. **理由**: 为什么这样认为

**避免的发言**:
- 完全不说话（容易被怀疑）
- 信息过少（没有价值）
- 过度激进（容易成为目标）
- 自相矛盾（暴露身份）

## 6. 信息不对称设计

这是狼人杀的核心机制，AI Arena必须严格实现。

### 6.1 信息可见性矩阵

| 信息类型 | 狼人 | 预言家 | 村民 |
|---------|------|--------|------|
| 自己角色 | ✅ | ✅ | ✅ |
| 队友身份（多狼局）| ✅ | ❌ | ❌ |
| 查验结果 | ❌ | ✅ | ❌ |
| 公开发言 | ✅ | ✅ | ✅ |
| 投票结果 | ✅ | ✅ | ✅ |
| 死亡信息 | ✅ | ✅ | ✅ |
| 夜晚行动 | 自己的 | 自己的 | ❌ |

### 6.2 实现要点

**后端**:
```python
def get_visible_state(player_id: str, game_state: GameState) -> Dict:
    """根据角色过滤信息"""
    player = game_state.get_player(player_id)
    
    # 所有人都能看到的公开信息
    visible = {
        "phase": game_state.phase,
        "round": game_state.round,
        "alive_players": game_state.alive_players,
        "dead_players": game_state.dead_players,
        "public_speeches": game_state.speeches,
        "vote_results": game_state.vote_results
    }
    
    # 角色特定信息
    if player.role == "werewolf":
        # 狼人看到队友（单狼局无队友）
        pass
    elif player.role == "seer":
        # 预言家看到查验历史
        visible["investigations"] = player.investigation_results
    # 村民无额外信息
    
    return visible
```

## 7. 边界情况处理

### 7.1 投票平票

**MVP处理**: 平票时无人出局，直接进入下一轮

**其他版本**:
- 平票PK：票数相同的玩家再次发言和投票
- 平票随机：随机选择一个出局
- 平票跳过：无人出局

### 7.2 首夜规则

**MVP处理**: 第一夜不杀人

**原因**:
- 平衡游戏，给好人更多信息
- 避免预言家/神职首夜出局

### 7.3 特殊情况

**同时死亡**:
- 女巫毒药和狼人杀同一人：算一次死亡
- 投票和毒药同一人：两次独立事件

**空轮**:
- 如果连续多轮无人出局，可能陷入僵局
- MVP版本：设置最大轮数限制（如10轮）

## 8. AI实现要点

### 8.1 推理要点

**预言家AI需要**:
- 决定何时跳身份
- 如何报查验结果
- 如何应对假预言家

**狼人AI需要**:
- 伪装技巧（不要表现得太像狼人）
- 选择杀人目标（优先杀神职）
- 是否假跳预言家

**村民AI需要**:
- 分析发言逻辑
- 识别矛盾
- 合理投票

### 8.2 记忆要素

AI需要记住：
- 每个玩家说过的话
- 投票历史
- 谁跳了什么身份
- 已知的身份信息

### 8.3 决策要素

**狼人杀人选择**:
- 优先级：预言家 > 其他神职 > 村民
- 避免杀守卫守护的目标
- 考虑是否刀女巫

**预言家查验选择**:
- 首夜：查验发言积极的
- 后续：查验怀疑对象或需要站队的

**投票选择**:
- 基于发言分析
- 基于身份判断
- 考虑阵营利益

## 10. MVP简化说明

为了快速验证核心概念，MVP做了以下简化：

**简化项**:
- ❌ 只有3个角色（狼人、预言家、村民）
- ❌ 5人局（最小可玩人数）
- ❌ 首夜不杀人
- ❌ 平票无人出局
- ❌ 没有女巫、猎人、守卫
- ❌ 没有遗言环节
- ❌ 没有警长竞选

**保留项**:
- ✅ 完整的夜晚-白天循环
- ✅ 预言家查验机制
- ✅ 发言和投票
- ✅ 信息不对称
- ✅ 胜利条件判断
