# 剧场环绕式观战界面重构计划

## 目标
把游戏运行时的观战界面从现在的「三栏控制台」重构为借鉴稿的**「剧场环绕式」**:玩家分左右两列环绕舞台,中间是带竖线+彩色圆点的事件时间线,AI 推理改为点击事件内展开的内联面板(不再常驻右栏)。完全采用借鉴稿的配色(深海军蓝 `#031427` + 金/绯红/蓝灰)、三套字体(EB Garamond / Source Sans 3 / DM Sans)、Material Symbols 图标、玻璃拟态 + 聚光灯氛围。

**数据层不动**:`useGameStream`、`types/api.ts`、API client、轮询逻辑全部保持不变,只改视觉/布局层。创建游戏页(`CreateGame`/`App.tsx` 外壳)用户明确说不用变,但会自动继承新的全局配色/字体。

## 已确认决策
- **结构**:剧场环绕式(照搬借鉴)—— 玩家左右分栏,中间时间线,推理内联展开
- **视觉**:完全采用借鉴稿配色 + 三套字体 + Material Symbols 图标
- **3D 已撤销**:不引入 three.js,纯 CSS/Tailwind

## 整体布局(重构 GameView)

```
┌─ 顶栏 GameHeader(🌙阶段 · 第N轮 · $成本 · 状态) ─────────── fixed ─┐
├───────┬───────────────────────────────┬───────┤
│ 参与者 │   事件时间线(主舞台)            │ 参与者 │
│ (左栏) │                               │ (右栏) │
│       │  ●━━ 夜幕降临… (竖线+圆点)       │       │
│玩家1  │  ●━━ 🐺狼人选择目标             │玩家4  │
│🐺存活 │      [🎭 揭开 AI 推理 ▼]        │👤存活 │
│       │      └ 内联推理面板(扫描线动画)  │       │
│玩家2  │  ●━━ 🔮预言家查验…              │玩家5  │
│👤死亡 │  ●━━ 玩家3发言(气泡+身份声明)    │🐺存活 │
│       │  ●━━ 🗳️ 投票结果(票数条)        │       │
│玩家3  │  ●━━ 💀 玩家死亡               │       │
│🔮存活 │  ●━━ 🏁 游戏结束               │       │
└───────┴───────────────────────────────┴───────┘
```
- 玩家按 index 拆分:前一半左栏,后一半右栏(5 人 → 左 2 右 3 或左 3 右 2,中间分界)
- 玩家卡按借鉴稿的 tarot 牌样式:🎭面具水印 + 玻璃拟态 + 角色 glow 边框
- 中间时间线:借鉴稿的 `timeline-line`(垂直渐变线)+ 每事件一个彩色圆点(夜=中性/狼=绯红/预言家=金/发言=蓝灰)
- AI 推理不再常驻右栏,改为时间线事件里的「🎭揭开 AI 推理」按钮 → 点击展开内联 `ai-reasoning-panel`(扫描线动画 + 引用斜体)

## 实施分 4 步

### 步骤 1:全局设计 token(配色/字体/图标/氛围)
**`frontend/tailwind.config.js`** — 扩展 colors 映射借鉴稿的 Nocturne Stage 色板:
- 新增 `nocturne.*` 命名空间:`stage #031427`(底)、`stage-bright #2a3a4f`、`container-lowest/low/high/highest`(深浅层级)、`on-surface #d3e4fe`、`on-surface-variant #c8c5cb`、`outline-variant #47464b`
- **角色语义色重新对齐借鉴稿**:seer=金 `#e9c400`(secondary-fixed-dim),werewolf=绯红 `#eb2445`(on-tertiary-container),villager=蓝灰 `#64748b`
- 字体族:`display: EB Garamond`(标题/玩家名/阶段)、`body: Source Sans 3`(对话/推理)、`label: DM Sans`(状态/时间戳/按钮)
- 圆角对齐借鉴稿:`DEFAULT .125rem / md .25rem / lg .5rem`
- 保留现有 keyframes(fade-in-up 等),新增 `scanline`(推理面板扫描线)

**`frontend/index.css`**:
- 字体 import 改为 EB Garamond + Source Sans 3 + DM Sans + Material Symbols Outlined(全部 Google Fonts)
- `:root` 背景改 `#031427`,文字 `#d3e4fe`
- 全局 `body::before` 聚光灯径向渐变(借鉴稿的 spotlight effect)
- `.glass-panel`(blur+半透明)、`.player-card`(🎭水印+角色glow)、`.ai-reasoning-panel`(扫描线)、`.timeline-line`、`.event-card` 这些借鉴稿核心 class 迁移过来
- `.card`/`.btn-*` 更新为新配色(金色主按钮、玻璃描边幽灵按钮)
- **保留 scroll 修复**:EventFeed 用 `scrollTop` 直赋而非 `scrollIntoView`(上次修的 bug 不能复发)

**`index.html`**:加 Material Symbols + Google Fonts preconnect(可选,已在 CSS import 里)

### 步骤 2:玩家卡(剧场环绕) — `game/PlayerTable.tsx` → 重构为 `PlayerCard` + 左右分栏
- `PlayerTable` 改为接收全部玩家,**按 index 分两半**,左半 + 右半各一列(由 GameView 把同一组件渲染两次,或组件内部 split)
- 单个玩家卡借鉴稿 tarot 样式:
  - 圆形头像(现有 `avatarColor` 保留,但叠角色色 ring)+ 玩家名(EB Garamond)+ 角色小标签(DM Sans)
  - 右上角状态 chip:`存活`(蓝灰)/`死亡`(灰)
  - **🎭 面具水印**(借鉴稿 `::after`,5% 透明度)
  - 狼人卡:`active-wolf` 绯红 glow 边框;死亡卡:`grayscale + opacity-60`
  - 发言中(`currentSpeaker`):金色 spotlight glow + 轻微浮起
  - 点击选中(`onSelectPlayer`):高亮,时间线里该玩家的事件可被关联
- 存活/死亡不再分两块,借鉴稿是混排(死亡卡灰掉即可),更紧凑

### 步骤 3:中央时间线 — `game/EventFeed.tsx` 重构 + `game/TimelineEvent.tsx`(新)
**`EventFeed.tsx`** 重构为时间线容器:
- 顶部标题区:`事件时间线`(EB Garamond 渐变文字)+ 副标题「观看 AI 思考、决策和博弈的全过程」
- `timeline-line` 绝对定位竖线(渐变:中性→金→绯红→中性)
- 每个事件渲染为 `TimelineEvent`(左侧圆点 + 右侧 event-card):
  - **圆点颜色随事件类型**:phase_change=中性灰、werewolf_kill=绯红(带 glow)、seer_investigate=金(带 glow)、speech=蓝灰、vote/death=中性
  - **event-card 边框**:狼人行动 `wolf-action`(绯红描边)、预言家 `seer-action`(金描边)、其余默认
  - 卡片头部:Material Symbols 图标 + 大写 label + 右上时间戳(从 `event.timestamp` 格式化 HH:MM:SS)
  - 戏剧化斜体叙述文案(借鉴稿风格):夜刀「狼人在黑暗中选择了一个目标」、查验「预言家注视着魔镜,探寻真相…」
- **保留** SpeechBubble(发言)、VoteResult(投票条形)的复用,只换皮
- **保留** 自动滚到底 + 用户上滚暂停(用 `scrollTop` 直赋,不用 scrollIntoView)
- **保留** 上帝视角:夜晚行动可见,标【私密】

**`game/TimelineEvent.tsx`(新)** — 单个时间线事件渲染(圆点+卡片+可展开推理),把现在 EventFeed 里散落的 `if(isWerewolfKill)...` 逻辑收敛到这里

### 步骤 4:内联 AI 推理面板 — 替代 `ReasoningSidebar.tsx`
**`game/AIReasoningPanel.tsx`(新,替代 ReasoningSidebar)** — 借鉴稿的 `ai-reasoning-panel`:
- 玻璃拟态深紫蓝渐变背景 + 左侧金色 2px 边
- **扫描线动画**(`::before` 横线从上往下移动,3s 循环)
- 内容:🎭图标 + 「内心独白 - 玩家X」(DM Sans 大写)+ 引用斜体推理文本(金色引号包裹)+ 标签 chips(威胁已评估/目标已锁定)
- 数据源:`getLatestReasoningForPlayer`(现有 hook 导出,保留)
- **触发方式**:时间线事件卡里的「🎭 揭开 AI 推理」按钮 → 展开/收起本事件的推理(每个有 reasoning 的事件一个)
- 删除/废弃 `ReasoningSidebar.tsx`(不再常驻右栏);`GameView` 移除右栏

### GameView.tsx 重构(组装)
```
<div 全高 flex 列>
  <GameHeader />  (顶栏,可改 fixed/sticky)
  <div flex-1 grid [左玩家栏 | 中时间线 | 右玩家栏] overflow-hidden>
    <PlayerTable players={左半} side="left" />
    <EventFeed events rounds status />  (内含可展开推理)
    <PlayerTable players={右半} side="right" />
  </div>
  {isCompleted && <ResultPanel />}  (浮层或底部,也换皮)
</div>
```
- 去掉右栏 `ReasoningSidebar`,中栏占主视觉
- ResultPanel 也套上新皮肤(金/绯红胜方色 + 玻璃卡)
