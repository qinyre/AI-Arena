## 2. 技术扩展

### 2.1 多模型适配器

#### 统一接口

```python
class ModelClient(ABC):
    """LLM客户端抽象基类"""
    
    @abstractmethod
    async def generate(
        self, 
        prompt: str, 
        reasoning_depth: str = "standard",
        json_mode: bool = True
    ) -> Dict:
        """生成响应"""
        pass
    
    @abstractmethod
    def get_usage(self) -> Dict[str, int]:
        """返回token使用情况"""
        pass
    
    @abstractmethod
    def estimate_cost(self, usage: Dict) -> float:
        """估算成本（美元）"""
        pass
```

#### 具体实现

```python
class ClaudeClient(ModelClient):
    """Claude API客户端"""
    def __init__(self, model_id: str):
        # 不硬编码模型列表，从配置读取
        self.model_id = model_id  # 如 "claude-3-5-sonnet-20241022"
        self.client = anthropic.Anthropic()
    
    async def generate(self, prompt, reasoning_depth, json_mode):
        # 根据reasoning_depth调整max_tokens
        max_tokens = {
            "quick": 500,
            "standard": 1500,
            "deep": 3000
        }[reasoning_depth]
        
        response = await self.client.messages.create(
            model=self.model_id,
            messages=[{"role": "user", "content": prompt}],
            max_tokens=max_tokens
        )
        
        return {
            "content": response.content[0].text,
            "usage": {
                "input_tokens": response.usage.input_tokens,
                "output_tokens": response.usage.output_tokens
            }
        }
```

### 2.2 性格系统实现

#### 性格影响Prompt

```python
def build_agent_prompt(
    role: str,
    visible_state: Dict,
    memory: str,
    personality: PersonalityProfile,
    available_actions: List[Dict]
) -> str:
    """根据性格调整系统提示词"""
    
    base_prompt = f"""你是狼人杀游戏中的AI玩家。
角色：{role}
当前局势：{visible_state}
历史记忆：{memory}
"""
    
    # 根据性格添加行为指引
    behavior_instructions = []
    
    if personality.aggression > 0.7:
        behavior_instructions.append("你倾向于主动指控可疑玩家，态度强硬。")
    elif personality.aggression < 0.3:
        behavior_instructions.append("你倾向于谨慎发言，避免直接冲突。")
    
    if personality.verbosity > 0.7:
        behavior_instructions.append("你喜欢详细阐述你的分析过程。")
    elif personality.verbosity < 0.3:
        behavior_instructions.append("你惜字如金，只说关键信息。")
    
    if personality.logic_oriented > 0.7:
        behavior_instructions.append("你高度重视逻辑推理和证据链。")
    
    if personality.emotional > 0.7:
        behavior_instructions.append("你会表达强烈的情绪和直觉感受。")
    
    if personality.suspicion > 0.7:
        behavior_instructions.append("你对其他玩家保持高度怀疑。")
    
    style_section = "\n行为风格：\n" + "\n".join(behavior_instructions)
    
    return base_prompt + style_section + f"\n\n可选动作：\n{json.dumps(available_actions, ensure_ascii=False, indent=2)}"
```
