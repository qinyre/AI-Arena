## 1. 项目概述

### 1.1 项目愿景

AI Arena 是一个让不同AI模型在多种游戏中互相博弈的竞技平台。用户可以观看AI在狼人杀、血染钟楼、剧本杀、斗地主等游戏中的表现，分析不同模型和性格配置的策略效果。

**核心价值**:
- **娱乐价值**: 观看AI互相推理、博弈、撒谎
- **研究价值**: 测试AI模型的社交推理和策略能力
- **教育价值**: 学习游戏策略，理解AI推理过程
- **技术价值**: 多智能体系统架构的实践案例

### 1.2 目标用户

**主要用户群体**:
1. **开发者和AI爱好者** - 贡献代码、创建性格模板、测试新游戏
2. **普通观众** - 观看AI对局，了解AI能力
3. **研究人员** - 使用平台进行AI能力基准测试

### 1.3 项目Slogan

**"Watch AIs Think, Compete, and Evolve"**  
*观看AI思考、竞争与进化*

## 3. 技术架构

### 3.1 整体架构选型

**架构方案**: 单体Python后端 + React前端

**选择理由**:
1. 开发速度快，技术栈成熟稳定
2. 社区友好，降低贡献门槛
3. 部署简单，易于分发
4. 后期可根据需要拆分微服务

### 3.2 技术栈

#### 后端技术栈
```yaml
语言: Python 3.11+
Web框架: FastAPI
数据库: SQLite (轻量级，适合单机部署)
ORM: SQLAlchemy
实时通信: WebSocket (通过FastAPI)
AI编排: LangChain (可选)
依赖管理: Poetry / pip-tools
```

#### 前端技术栈
```yaml
框架: React 18 + TypeScript
UI库: Tailwind CSS
动画: Framer Motion
Canvas渲染: Konva.js / Fabric.js (游戏场景)
状态管理: Zustand / Context API
构建工具: Vite
```

#### LLM集成
```yaml
支持模型:
  - Claude (Anthropic API)
  - GPT-4 / GPT-3.5 (OpenAI API)
  - Gemini (Google AI)
  - 本地模型 (Ollama)
```

#### 部署
```yaml
容器化: Docker + Docker Compose
CI/CD: GitHub Actions
文档: MkDocs
```

### 3.4 核心数据流

#### 对局启动流程
```
用户配置 → GameOrchestrator → 
初始化Game → 初始化AIAgents → 开始游戏循环
```

#### 单轮决策流程
```
Game.get_current_player() → 
Agent.perceive(visible_state) → 
Agent.think() [调用LLM] → 
Agent.decide() → 
Game.apply_action() → 
EventBus.broadcast() → 
Frontend实时更新
```

## 4. 系统设计

### 4.1 游戏引擎设计

#### BaseGame 抽象接口

所有游戏必须实现的核心接口：

```python
class BaseGame(ABC):
    @abstractmethod
    def initialize(players, config) -> None
        """初始化游戏，分配角色"""
    
    @abstractmethod
    def get_visible_state(player_id) -> Dict
        """获取特定玩家可见的游戏状态（信息过滤）"""
    
    @abstractmethod
    def get_available_actions(player_id) -> List[GameAction]
        """获取玩家当前可执行的动作列表"""
    
    @abstractmethod
    def is_valid_action(action) -> bool
        """验证动作是否合法"""
    
    @abstractmethod
    def apply_action(action) -> List[Event]
        """应用动作，返回产生的事件列表"""
    
    @abstractmethod
    def check_win_condition() -> Optional[WinInfo]
        """检查胜利条件"""
    
    @abstractmethod
    def get_game_summary() -> Dict
        """返回游戏总结数据"""
```

#### 信息过滤机制

**核心原则**: 每个AI只能看到其角色允许看到的信息

**实现方式**:
- `get_visible_state(player_id)` 根据玩家角色返回过滤后的状态
- 狼人：可以看到队友身份
- 预言家：可以看到查验历史
- 村民：只能看到公开信息

### 4.2 AI智能体设计

#### AIAgent 核心架构

```
感知 (Perceive) → 思考 (Think) → 决策 (Decide) → 交流 (Communicate)
      ↓                ↓              ↓                ↓
   更新记忆        调用LLM推理    选择动作         生成发言
```

#### 性格系统

**性格维度** (0-1之间的浮点数):
- `aggression`: 激进度 (影响指控倾向)
- `suspicion`: 怀疑度 (影响信任阈值)
- `verbosity`: 话痨度 (影响发言长度)
- `logic_oriented`: 逻辑性 (影响推理风格)
- `emotional`: 情绪化 (影响表达方式)
- `risk_tolerance`: 风险偏好 (影响策略选择)

**预设性格模板**:
1. **福尔摩斯型** - 高逻辑、低情绪、详细分析
2. **激进指控型** - 高进攻、高怀疑、直接指控
3. **沉默观察型** - 低话痨、高逻辑、关键时刻发言
4. **情绪煽动型** - 高情绪、高话痨、擅长煽动
5. **理性分析型** - 平衡型，依赖数据和逻辑

**性格库系统**:
- 预设模板存储在 `config/personalities/`
- 用户可创建自定义性格并保存
- YAML格式配置文件

#### 记忆系统

**MVP阶段 - 短期记忆 (ShortTermMemory)**:
- 存储当局所有事件
- 按时间序列组织
- 提供检索接口给推理模块
- 对局结束后清空

**数据结构**:
```python
{
    "events": [
        {"round": 1, "phase": "night", "event": "player_killed", ...},
        {"round": 2, "phase": "day", "speaker": "AI-1", "speech": "...", ...}
    ],
    "player_statements": {
        "AI-1": ["我是预言家", "我查验了AI-2是好人"],
        "AI-2": [...]
    },
    "voting_history": [
        {"round": 1, "votes": {"AI-1": "AI-3", ...}}
    ]
}
```

**未来扩展 - 长期记忆**:
- 使用向量数据库 (Chroma/Qdrant)
- 存储成功策略模式
- 跨对局学习和优化

#### 推理深度配置

**三个档位**:
1. **Quick (快速)** - 简化推理，快速决策
   - 成本: ~$0.01/决策
   - 适用: 日常测试、快速演示

2. **Standard (标准)** - 平衡推理深度
   - 成本: ~$0.03/决策
   - 适用: 正常对局

3. **Deep (深度)** - 完整推理链，多层分析
   - 成本: ~$0.08/决策
   - 适用: 展示极限能力、研究

### 4.3 LLM集成设计

#### ModelManager

**职责**:
- 管理多个LLM提供商
- 统一接口调用
- 成本追踪
- 失败重试和降级策略

**支持的提供商**:
```yaml
Claude:
  models: [claude-3-opus, claude-3-sonnet, claude-3-haiku]
  
OpenAI:
  models: [gpt-4, gpt-4-turbo, gpt-3.5-turbo]
  
Google:
  models: [gemini-pro, gemini-ultra]
  
Ollama (本地):
  models: [llama2, mistral, mixtral]
```

#### 配置示例

```yaml
# config/models/default.yaml
players:
  - id: "AI-1"
    model:
      provider: "claude"
      model: "claude-3-sonnet"
      reasoning_depth: "standard"
    personality: "sherlock"
  
  - id: "AI-2"
    model:
      provider: "openai"
      model: "gpt-4"
      reasoning_depth: "deep"
    personality: "aggressive"
  
  - id: "AI-3"
    model:
      provider: "ollama"
      model: "llama2"
      reasoning_depth: "quick"
    personality: "silent"
```

### 4.4 数据分析设计

#### 统计指标

**玩家级别统计**:
- 胜率 (按角色、按阵营)
- 平均存活轮数
- 投票准确率
- 发言频率

**模型对比**:
- Claude vs GPT-4 胜率对比
- 不同模型的平均决策时间
- 成本效益分析

**性格效果分析**:
- 各性格的胜率分布
- 性格维度与胜率的相关性
- 最优性格组合推荐

#### 对局总结

**AI生成的总结**:
- 使用LLM分析完整对局记录
- 生成文字总结 (关键转折点、精彩操作、失误分析)
- 评选MVP

**结构化数据**:
```json
{
  "game_id": "...",
  "duration": "15分32秒",
  "winner": "狼人阵营",
  "mvp": "AI-2 (狼人)",
  "key_moments": [
    {"round": 3, "description": "AI-1成功识破AI-2的谎言"},
    {"round": 5, "description": "AI-2反杀预言家，扭转局势"}
  ],

}
```
