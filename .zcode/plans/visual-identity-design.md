# AI Arena 视觉设计方案 - 专业版

## 📋 设计简报分析

### 项目核心
- **主题**: AI 在社交推理游戏中的博弈
- **关键词**: 欺骗、推理、面具、真假、博弈
- **用户情感**: 好奇、惊讶、洞察

### 避免的设计陷阱
❌ 通用的紫蓝渐变 (#7C3AED / #3B82F6)
❌ 酸性荧光绿 (#00FF00) 在黑背景上
❌ 奶油色背景 (#F4F1EA) + 赤陶色
❌ 报纸风格的细线分割
❌ 千篇一律的打字机效果

---

## 🎨 三个独特视觉方向

### 方向 1: "侦探推理" (Detective Noir)

**核心概念**: 像侦探破案一样观察 AI 的推理链

**色彩系统**:
```
--bg-primary: #1a1512 (深棕墨色 - 旧案卷的颜色)
--bg-secondary: #2d2419 (烟草棕)
--accent-clue: #d4af37 (金色 - 关键线索)
--accent-truth: #e8dcc4 (羊皮纸色 - 真相)
--accent-lie: #8b4513 (锈红棕 - 谎言标记)
--text-primary: #f5f1e8 (温暖白)
```

**字体**:
- Display: Playfair Display (衬线 - 侦探小说封面感)
- Body: Inter (现代无衬线 - 可读性)
- Mono: JetBrains Mono (代码/数据)

**关键元素**:
- 推理过程用"证据卡片"展示
- 时间线像"侦探墙上的红线"连接事件
- AI 思考用"档案夹"打开效果
- 签名元素: **放大镜扫描效果** - hover 事件时出现放大镜扫描线

**布局**:
```

│  🔍 AI Arena                       │
│  观察·推理·真相                     │
├────────────────────────────────────┤
│                                    │

│  │ 🎭  │     ╲         ╱           │
│  │      │      ◉─────◉             │
│  └──────┘      事件网络             │
```

## 🎯 推荐方案：方向 2 "面具剧场"

### 为什么选择这个方向？

1. **主题契合度最高**: 狼人杀的核心是"隐藏身份"，面具是最直观的隐喻
2. **视觉独特性**: 戏剧化的面具元素不会与常见的 AI 设计重复
3. **情感共鸣**: 用户能立即理解"面具翻转 = 揭示真相"的隐喻
4. **实现可行性**: 面具动画和分割线效果技术上可行且有冲击力

### 签名元素：双面面具

**核心动画**:
```
展开推理前:
🎭 (完整面具)

展开推理时:
🎭  →  🎭│🎭  →  [推理内容]
      (面具从中间分开，露出内容)
```

## 📐 细节规范

### 间距系统
- 舞台边距: 24px
- 卡片内边距: 20px
- 元素间距: 16px
- 微间距: 8px

### 圆角
- 卡片: 8px (略方，像舞台布景)
- 按钮: 6px
- 标签: 4px

### 阴影
- 舞台深度: 0 8px 32px rgba(0,0,0,0.6)
- 卡片浮起: 0 4px 16px rgba(0,0,0,0.4)
- 面具阴影: 0 2px 8px rgba(61,47,74,0.5)

## ✅ 设计自我批评

**避免的陷阱**:
- ❌ 不要过度使用面具 emoji - 只在关键处使用
- ❌ 不要让戏剧化变成卡通化 - 保持优雅
- ❌ 不要用太多金色 - 真相金色仅用于高光时刻

**质量标准**:
- ✅ 任何设计决策都要回答："这为什么适合狼人杀？"
- ✅ 面具元素必须克制使用，成为记忆点而非噪音
- ✅ 色彩对比度满足 WCAG AA 标准
